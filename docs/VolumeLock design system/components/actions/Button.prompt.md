Botón de acción M3; úsalo para cualquier acción explícita del usuario (guardar, abrir ajustes, revertir).

```jsx
<Button variant="filled" icon="lock" onClick={activar}>Activar candado</Button>
```

Variantes: `filled` (una sola por pantalla), `tonal`, `outlined`, `text`, `danger`. Etiquetas en imperativo corto y mayúscula sólo inicial.
